# 在线二维码识别

> 上传二维码图片即可在本地解码识别内容，支持拖拽文件。

在线体验：https://wangchenyu.com/gongju/qrscanner/

## 功能特性

- 图片上传 / 拖拽解码
- 识别结果文本与链接展示
- 纯浏览器本地识别

## 使用方法

1. 用浏览器直接打开 `index.html`，无需安装任何软件、无需构建、无需后端服务。
2. 所有计算与处理均在浏览器本地完成，数据不会上传到服务器。
3. 处理完成后使用页面上的复制 / 导出按钮即可保存结果。

## 技术栈

JavaScript llqrcode 解码库

## 目录结构

```
├── index.html        # 主页面
├── assets/ 或本地资源 # 样式、脚本与静态资源（按需）
```
